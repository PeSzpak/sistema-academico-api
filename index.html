Sistema Acadêmico - API de Alunos

API REST em PHP + MySQL feita para o desafio da Faculdade Senac. Esta página é um painel de testes: consome a mesma API que a secretaria usaria, mostrando na prática as respostas de sucesso e de erro.

Endpoints da API

MétodoRotaO que faz
GETindex.phpLista todos os alunos
GETindex.php?id=1Busca um aluno específico
GETindex.php?curso=ADSFiltra alunos por curso
POSTindex.phpCadastra um novo aluno (corpo JSON)
PUTindex.php?id=1Atualiza um aluno (corpo JSON)
DELETEindex.php?id=1Exclui um aluno
